## 변경 사항
- 유저 프로필 사진 추천 18장 별도 코너: `USER ICONS` 메뉴 / 꽃·음악·일상·기술·군경 필터 / 원본 PNG 확대·다운로드.

- 기존 세계관·세 NPC·인트로·BGM 4곡·공개 갤러리·스튜디오 기능 유지.

## 배포
ZIP을 압축 해제해 **다른 GitHub 계정의 실제 홈페이지 저장소** 루트에 업로드하세요. 해당 계정의 저장소 주소는 아직 제공되지 않아 **원격 GitHub에 직접 업로드하지 않았습니다.** `index.html`, `persona.js`, `user-portraits.js`, `user-portraits.css`, `assets/user-portraits/*`를 반드시 함께 올리세요.

> GitHub Pages는 정적 사이트라 다운로드만 지원합니다. 복사·다운로드한 프로필 정보는 외부 서버에 보내지지 않습니다.
