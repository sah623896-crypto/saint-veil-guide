중요: 이 페이지에서는 GitHub에 자동 업로드하지 않아요.

파일은 현재 브라우저에서만 임시로 처리되며, 새로고침하거나 탭을 닫으면 목록이 사라집니다. 반드시 ZIP을 먼저 다운로드해 주세요. 공개 폴더에 올린 이미지는 누구나 볼 수 있으므로 개인 백업은 별도 보관을 권장해요.

어떻게 홈페이지에 반영하나요?

  1. 공개할 이미지만 상태 → 공개로 선택하고 공개용 ZIP을 다운로드하세요.
  2. 압축을 풀어 assets/gallery/ash, ian, luca, world별로 이미지가 정리됐는지 확인하세요.
  3. 홈페이지를 게시한 해당 GitHub 계정으로 로그인한 다음, 저장소에서 각 assets/gallery/... 폴더에 이미지를 업로드하고 커밋하세요.
  4. 배포 후 홈페이지의 ALBUM에서 자동으로 확인할 수 있어요. 사이트 이름이나 계정명이 달라도 GitHub Pages 주소에서 저장소를 자동 인식합니다.
